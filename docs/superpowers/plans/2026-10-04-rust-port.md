# ttype Rust Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reimplement the Go `ttype` terminal typing trainer in idiomatic, safe Rust with behavioral parity and a new safe-Rust practice mode.

**Architecture:** A library crate owns portable domain types, text generation, session state, statistics, persistence, replay encoding, update safety, and terminal-independent rendering. The binary composes a single-threaded `crossterm` event loop and `ratatui` views around the library, with Clap-derived commands at the boundary. Go remains an immutable behavior oracle at `/root/ttype`; golden tests encode its tested outcomes rather than changing semantics.

**Tech Stack:** Rust 1.98.1/Cargo, `ratatui` + `crossterm`, `clap` v4 derive + `clap_complete` + `clap_mangen`, `serde` + `toml`, `dirs`, `thiserror`, `anyhow`, `rand_chacha`, `sha2`, `ureq`, `proptest`.

**Spec:** User request issued 2026-10-04; Go reference at `/root/ttype`.

## Global Constraints

- Place all new work in `/root/ttype-rs`; never edit `/root/ttype`.
- Add crate-level `#![deny(unsafe_code)]`; no `unsafe`, `unwrap`, or `expect` on fallible paths.
- Pin every dependency to an exact registry version; use no git dependencies and no async runtime.
- Embed shipped practice lists through `include_str!`; runtime is offline except the optional update check.
- Match Go formulas and thresholds exactly: WPM/raw WPM/accuracy rounding (`internal/stats/stats.go:11-36`), consistency curve (`internal/stats/stats.go:49-84`), session timing and min-WPM limits (`internal/engine/session.go:18-29`, `450-464`, `618-674`), heatmap ordering (`internal/stats/stats.go:91-112`), and replay scheduling (`internal/tui/replay_model.go:32-146`).
- Preserve modes `words`, `sentences`, `go`, `python`, `sql`, `shell`, `regex`, `backend`, `custom`; add code-mode `rust` where all selectable modes are registered.
- Every milestone runs `cargo fmt --all --check && cargo clippy --all-targets -- -D warnings && cargo test --all-targets` and records the literal output.

## Review Focus

- Timed runs must not finish before first accepted key or exceed their rated one-second floor; test with fake monotonic time in M1.
- Word-commit modes must preserve skip sentinels/extras while code modes count whitespace, tabs, braces, angle brackets, and newlines literally; test in M1/M4.
- Persistence must honor XDG paths and atomically survive absent/corrupt data files; test in M3.
- User-provided text must reject conflicting inputs and normalize exactly as the Go cleaner; test in M3.
- Update data must be checksum-verified before an atomic replacement and must retain the installed executable on all failures; test in M5.
